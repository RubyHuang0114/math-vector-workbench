# VECTOR 数学行动台

独立于英语工作台的七上数学复习应用。内容主线为整式运算、提公因式、公式法、十字相乘、分组与整体、综合与新情境。参考桌面因式分解目录24份PDF的考点，首版72个重新编写并核验的任务，不宣称已完整收录378页原题。

## 使用

打开网址或index.html。电脑、手机均可；数学表达式输入小写字母，例如 `6x(x-2)(x+2)`、`x^2`、`(a+b)^2`。支持隐式乘法、有限小数、常数分母与括号，自动规范部分中文符号。不执行输入代码，不支持当前阶段以外的字母分母或任意开放证明批改。

## 首版机制

- 每模块简易、中档、难/压轴三档自由进入，无强制先通关与自动降级。难档表示本范围挑战，不冒充中考压轴难度。
- 演算＋结构辨析、独立挑战与按需线索；原题修复与同模块变式分开。
- 临时草稿、自由圈画、条件关系板、正式演算区、数学快捷键。可暂停保存。圈画保存在本机草稿中，不做手写识别；正式判题使用确认后的表达式。
- 精确有理数多项式逐行等价检验；与最终任务达成检查分开。接受因式交换、负号转移和其他等价路线；对已核验目标的不可约因式结构检查彻底程度，不冒充通用因式分解引擎。
- 正确答案、关键过程待补、提示辅助分别记录。难档演算需留下至少一行核心变形；简单题允许一步到位。
- 错题保留原始演算和首错位置，再由孩子确认概念/方法/习惯等候选原因；不凭一次错误诊断心理状态。
- 给出一个可执行修复动作；后续不同组到期独立正确两次才修复原题。同模块变式优先按诊断大类选；更细粒度同错因题库仍需扩充。
- 查看参考路线后24小时内重做按辅助计，不能冒充独立；近期熟练度按模块×难度，每题取最近一次独立结果，避免重复刷熟题主导正确率。
- 自报终点检查和卷面过程分别记录，不能把勾选当成实际能力证明。
- 原创任务地图、工具卡和撤离复盘视觉，轻音阶奖励，可关闭；无强制倒计时、速度榜和失败清空机制。

## 数据

本地存储键 `vector-math-action-v1`，与英语完全独立。无远程学习数据上传，无账号服务；电脑手机各自保存，可在资料设置中备份、迁移、下载报告。导入需确认替换当前档案。历史记录最多20000条。

## 开发与扩充

`node verify.cjs` 验证判题、所有参考路线、三个难度、错题修复、原题重试与备份。当前有496项检查。

运行 `python -m http.server 4188 --bind 127.0.0.1` 后打开本地页面。运行时无外部CDN依赖。

`build_content.py` 生成data.js；题目ID必须保持稳定。每题包含module、level、kind、family、start/target/steps或options/answer、source、origin、checkpoint。新增单元应新增模块/稳定ID，增加对应判题能力与验证后发布。当前分式方程作为后续独立模块，不把未支持的题型混入判题。

发布仅包含应用代码、重新编写的题库和来源说明；不含原PDF、完整抽取文本、本机路径和学习档案。


## 追加约束：纯数学与过程证据

不将心理原因纳入判断：不推测注意力、心态、动机、情绪或认知态度。仅依据表达式等价性、公式适用条件、任务完整性、数学辨析与后续作答表现反馈。环节选择是修复工具，不是人格或心理标签。难度由孩子选择；同档查证可跳过，不自动降级。体验重心是短反馈、局部修改、可见突破和主动挑战，不靠延长复盘问卷制造负担。
