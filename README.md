# VECTOR 数学行动台 · 原题版

题库只采用桌面“因式分解”文件夹原题。题干、图示和配套解析均以原PDF截取展示。学年、地区、考试类型照原题括注，每题可追溯文件、PDF页码和题号。

当前已建立24份资料的13组对应关系，涵盖598条原题记录：按原大题计数，保留小问与原编号；不同文件重复出现的题保留各自出处，不宣称去重题量。具体自动答案核对 / 原稿复核数量以原题对应清单和页面实时计数为准。

自动核对支持选择、表达式、多问、分类讨论、比和因式分解等式。原稿复核支持完整书写、圈画、提交前解答快照、原解析对照，以及差异位置 / 修正依据 / 下次检查动作记录。自查一致不等于系统判定正确，不计入掌握率，也不自动清除历史错题。尚未实现所有题目的完整过程自动批改。

独立《整式应用题》12道中11道支持答案核对，最后一道四小问含作图说明，采用完整书写与原稿复核。“七大题型”68道全部可进入作答，其中8道采用原稿复核。因式分解期中汇编包括12道典例及53道迁移/综合题。分式方程应用作为扩展资料，可从资料索引进入，默认混合行动不抽取。

旧版72道自编题全部撤下，不能进入练习、推荐、错题回练或当前掌握度评估。保留历史存档身份，不向网站发布旧自编题干与解析。没有额外生成的辨析题。

## 使用与核验

各模块简易、中档、难/压轴自由选择。难度为工作台整理标签；题数不足按实际题数，不换档、不编题补位。选择、表达式、分类讨论多值和多小问均按原题要求配置。

数学输入如 x^2、2x(x-1)，支持隐式乘法、有限小数、常数分母；精确有理数多项式逐行核验，并检查分解彻底/合并完成。条件列式题不预先透露列式结果；答案结果与文字说理分别记录，未自动核验的论证不计为完整掌握。

错题保留原答、出错行与分问演算，原解析保留原文不改写。临时草稿、圈画、条件板与正式演算分别保存。没有心理原因判断或自动降难度。查看解析后24小时内重做按辅助记；后续两次到期独立复查才可修复原题，文字证明待核验不据此判为掌握。

## 数据与步骤分

数学项目、网址和存储键vector-math-action-v1与英语独立。学习档案仅保存在当前浏览器，电脑手机可导出/导入迁移。上海教育考试院公开评析重视过程与结果；尚未获得可核验的逐题官方步骤分细则，不虚构固定扣分、官方分值或考试预测分。见RESEARCH.md。

## 维护

运行node verify.cjs或node verify_originals.cjs，核验原图定位和哈希、原解析答案、分类讨论漏解、多问判题、错题复查、旧题隔离与存档。运行python -m http.server 4188 --bind 127.0.0.1预览。

expand_originals.py建立逐题目录与原图定位；extract_choice_keys.py只提取有明确A—D选项及唯一原答案字母的单选题；build_original_bank.py配置来源与答案识别。curate_originals.py为早期局部导入脚本，已停用。新增题必须有明确的原题、解析对应。旧版build_content.py及其他一次性改写脚本已停用，不能生成当前题库。

发布应用代码、配对原题/解析截取及来源说明，不发布整份PDF、抽取全文、本机绝对路径或学习档案。
